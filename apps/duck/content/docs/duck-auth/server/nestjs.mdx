The handlers take Nest's Express request and response, so this needs `@nestjs/platform-express`.

```ts title="auth.controller.ts"
import { Controller, Get, Post, Req, Res } from '@nestjs/common'
import {
  type NestAdapter,
  nestProviderBegin,
  nestProviderCallback,
  nestSession,
  nestSignIn,
  nestSignOut,
} from '@gentleduck/auth/server/nestjs'
import { auth } from './auth'

@Controller('auth')
export class AuthController {
  @Post('signin')
  signIn(@Req() req: NestAdapter.Request, @Res() res: NestAdapter.Response) {
    return nestSignIn(auth)(req, res)
  }

  @Post('signout')
  signOut(@Req() req: NestAdapter.Request, @Res() res: NestAdapter.Response) {
    return nestSignOut(auth)(req, res)
  }

  @Get('session')
  session(@Req() req: NestAdapter.Request, @Res() res: NestAdapter.Response) {
    return nestSession(auth)(req, res)
  }

  @Post('providers/:id/begin')
  begin(@Req() req: NestAdapter.Request, @Res() res: NestAdapter.Response) {
    return nestProviderBegin(auth)(req, res)
  }

  @Get('providers/:id/callback')
  callback(@Req() req: NestAdapter.Request, @Res() res: NestAdapter.Response) {
    return nestProviderCallback(auth)(req, res)
  }

  @Post('providers/:id/callback')
  formCallback(@Req() req: NestAdapter.Request, @Res() res: NestAdapter.Response) {
    return nestProviderCallback(auth)(req, res)
  }
}
```

- Apple returns the browser with a form POST, so the callback is mounted for both GET and POST. Nest parses the form body by default.

- The IP the session records is `req.ip`, so set Express's `trust proxy` through `app.set('trust proxy', 1)` on the Nest app.
- The callback answers the session cookies and an empty 200. To land the browser on a page, write the callback yourself, as on the [OAuth page](/duck-auth/providers/oauth#the-routes).

## Gating sign-in

`nestSignIn(auth, { onAuthenticated })` runs your check once the credentials verify, before the response is written. Answer a denial and the new session is revoked, so the client never sees it:

```ts
nestSignIn(auth, {
  onAuthenticated: async ({ session }) =>
    session && (await isSuspended(session.identityId))
      ? { code: 'ACCOUNT_SUSPENDED', status: 403, detail: 'contact support' }
      : undefined,
})
```

It runs after the password is checked, so a denial tells nothing to someone who does not know it.

## Your own routes

```ts
import { Controller, type MiddlewareConsumer, Module, type NestModule, Post, UseGuards } from '@nestjs/common'
import type { Identities } from '@gentleduck/auth/core'
import { CurrentIdentity, makeGuard, nestActorContext } from '@gentleduck/auth/server/nestjs'

@Controller('api')
@UseGuards(makeGuard(auth))
class ProfileController {
  @Post('profile')
  update(@CurrentIdentity() identity: Identities.Me | null) {
    return updateProfile(identity)
  }
}

@Module({ controllers: [AuthController, ProfileController] })
export class AppModule implements NestModule {
  configure(consumer: MiddlewareConsumer) {
    consumer.apply(nestActorContext(auth)).forRoutes('*')
  }
}
```

| Piece | Does |
| --- | --- |
| `makeGuard(auth)` | Refuses a request with no session with `AUTH_UNAUTHENTICATED`, and checks CSRF. `{ required: false }` lets anonymous requests through; `{ csrf: false }` skips the check. |
| `makeCsrfGuard(auth)` | The CSRF check alone. |
| `@CurrentIdentity()`, `@CurrentSession()` | What the guard or the middleware resolved. |
| `nestActorContext(auth)` | Binds the actor for everything downstream. The guard reuses the session it resolved, so the pair reads it once. |
| `NestExceptionFilter` | Answers an `AuthError` at its status: `app.useGlobalFilters(new NestExceptionFilter())`. |

`nestCaller(req)` is the IP and User-Agent to pass to a flow you call yourself.
