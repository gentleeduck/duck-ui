The Next.js adapter is plain `(req: Request) => Promise<Response>` with no Next import, so it serves any Fetch runtime. On Bun:

```ts
import { mountNext, nextWithActor, withNextCsrf } from '@gentleduck/auth/server/next'

const { GET, POST } = mountNext(auth)
const profile = withNextCsrf(auth, nextWithActor(auth, updateProfile))

Bun.serve({
  fetch(req) {
    const { pathname } = new URL(req.url)
    if (pathname.startsWith('/auth/')) return req.method === 'POST' ? POST(req) : GET(req)
    if (pathname === '/api/profile') return profile(req)
    return new Response('Not found', { status: 404 })
  },
})
```

Deno's `Deno.serve` and a Worker's `fetch` take the same function. A `Request` carries no client IP, so sessions record only the User-Agent; to record the IP, write the sign-in route yourself, as below.

## Building blocks

`@gentleduck/auth/server/generic` is what every adapter is built from:

| Export | Does |
| --- | --- |
| `executeIntents(intents)` | A flow's intents as a `Response`: cookies, redirect, JSON body, `no-store`. Refuses an unsafe redirect. |
| `errorResponse(err)` | A thrown error as the adapters answer it, the cause of a 5xx logged and withheld. `errorToHttp` is the same as `{ status, body }`. |
| `jsonResponse(status, body)` | A JSON `Response` with `no-store`. |
| `readBodyJson(req)`, `readBodyText(req)` | The body, `null` past 100 KiB or when it does not parse. |
| `parseSignInBody`, `parseProviderBeginBody`, `parseBodyStringField` | Validate a parsed body. |
| `oauthCallback(auth, id, req, caller)` | Finishes an OAuth sign-in from the callback's query or form body. |
| `redirectForScript(intents, headers)` | Turns `begin`'s redirect into `{ url }` JSON for a request that accepts JSON: a script cannot follow a redirect to the IdP. |
| `callerContext({ ip, userAgent })` | The caller fingerprint a flow takes, trimmed to what the session row holds. |
| `requestSecurity(auth, { caller })` | The hijack and anomaly hooks the actor wrappers run. |
| `nodeHeadersToFetch(headers)` | A Node header object as `Headers`. |
| `isSafeRedirectUrl`, `isValidProviderId`, `serializeCookie` | The checks and cookie writer the rest use. |

A sign-in route that records the IP:

```ts
import { csrfGuard } from '@gentleduck/auth/core'
import { callerContext, errorResponse, executeIntents, parseSignInBody, readBodyJson } from '@gentleduck/auth/server/generic'

async function signIn(req: Request, ip: string): Promise<Response> {
  try {
    await csrfGuard(auth, req)
    const body = parseSignInBody(await readBodyJson(req))
    if (!body) return executeIntents([{ type: 'error', code: 'AUTH_INVALID_CREDENTIALS', status: 400 }])
    const { intents } = await auth.flows.signIn({
      ...body,
      ...callerContext({ ip, userAgent: req.headers.get('user-agent') }),
      previousSid: auth.transport.extract(req) ?? undefined,
    })
    return executeIntents(intents)
  } catch (err) {
    return errorResponse(err)
  }
}
```

`previousSid` lets the flow revoke the session the browser held before, so signing in again never leaves two.
