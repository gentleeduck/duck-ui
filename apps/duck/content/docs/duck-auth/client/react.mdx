```tsx
import { Provider } from '@gentleduck/auth/client/react'

export function App({ children }: { children: React.ReactNode }) {
  return <Provider baseUrl="/auth">{children}</Provider>
}
```

`Provider` takes the [vanilla client's options](/duck-auth/client/vanilla), or a built one as `client`. It reads the session on mount; `noInitialFetch` skips that read and starts as a guest.

## The session

```tsx
import { useSession } from '@gentleduck/auth/client/react'

type Profile = { username: string; email: string; displayName?: string }

function Header() {
  const { data, status } = useSession<Profile>()
  if (status === 'loading') return null
  if (status === 'guest') return <a href="/sign-in">Sign in</a>
  return <span>{data.identity?.profile.displayName ?? data.identity?.profile.email}</span>
}
```

`status` is `loading` until the first read lands, then `authed` or `guest`. `refresh()` reads it again.

## Signing in and out

```tsx
import { useSignIn } from '@gentleduck/auth/client/react'
import { type FormEvent, useState } from 'react'

function SignInForm() {
  const signIn = useSignIn()
  const [error, setError] = useState<string | null>(null)

  async function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault()
    const form = new FormData(event.currentTarget)
    const res = await signIn.mutate({
      providerId: 'password',
      input: { email: form.get('email'), password: form.get('password') },
    })
    setError(res.ok ? null : res.error.code)
  }

  return (
    <form onSubmit={submit}>
      <input name="email" type="email" required />
      <input name="password" type="password" required />
      <button type="submit" disabled={signIn.loading}>Sign in</button>
      {error === 'AUTH_INVALID_CREDENTIALS' && <p>Wrong email or password</p>}
    </form>
  )
}
```

Every mutation hook answers `{ mutate, loading, error }`. `mutate` resolves to the call's [envelope](/duck-auth/client#what-a-call-answers), so a refusal is `res.ok === false`, not a throw; `error` holds only a thrown error. On success the session updates everywhere `useSession` is read.

| Hook | `mutate` takes |
| --- | --- |
| `useSignIn()` | `{ providerId, input }` |
| `useSignOut()` | nothing |
| `useBeginProvider()` | `{ id, input }`: `mutate({ id: 'oauth:google' })` sends the page to Google, `mutate({ id: 'magic-link', input: { email } })` sends the link. |
| `useSignUp({ path })` | Your registration route's body. No adapter mounts one. |

`useAuthClient()` is the client itself, for a call no hook covers.

## Storybook

```ts title=".storybook/preview.ts"
import { authWithStorybook } from '@gentleduck/auth/client/react/storybook'

export const decorators = [
  authWithStorybook({ identity: { id: 'demo', profile: { username: 'demo', email: 'demo@example.com' } } }),
]
```

Each story renders against a mock client that answers that identity; leave it out for a guest. A story's `parameters.auth` overrides it, and `parameters: { auth: { live: true } }` swaps in a real client against `baseUrl`, `http://localhost:8787/auth` by default. `authCreateMockClient(state)` is the mock alone.
